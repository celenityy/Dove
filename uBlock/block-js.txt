! JavaScript (JS) has significant privacy and security concerns, but blocking it typically causes severe breakage.

! This isn't really the case for Thunderbird though; we only need JavaScript for ex. certain email providers so users can sign-in.

! It's typically preferable to block JS via uBlock Origin's `Disable JavaScript` feature, but we unfortunately can't set that without locking it.
! Blocking JavaScript with a filterlist like this allows users to override and re-enable it if desired, as well as control site exceptions, etc.
